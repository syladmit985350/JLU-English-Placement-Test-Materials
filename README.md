# 吉林大学研究生入学英语分级考试 · 模拟机考系统（离线版）

一个完全离线、双击即用的**模拟机考系统**，1:1 还原吉林大学研究生入学英语分级上机考试系统的界面结构与考试流程，内置 6 套全真模拟卷及详解、10 段听力音频。

---

## 一、如何使用

1. **解压**本压缩包到任意目录（注意：`index.html` 必须和 `data.js`、`audio` 文件夹放在同一目录下）。
2. **双击 `index.html`**，用浏览器（推荐 Chrome / Edge）打开即可，**无需联网、无需服务器、无需安装任何软件**。
3. 先**登录**：用户名输入学号、密码输入证件号后 6 位（例如证件号 `23123419810123912X`，密码为 `23912X`），点击「Login」。
4. 登录后**选择一套模拟卷**（学号已自动带入，可补填姓名），点击「开始考试」。

> 首页（登录页）还提供了「📄 PDF文件下载」入口，可直接下载完整的《全真模拟卷及详解》PDF 原卷，方便对照打印或查看听力原文、详解、范文。

> 提示：不要单独把 `index.html` 拖到别处，否则听力音频会找不到。保持整个文件夹结构不变。

## 二、系统功能（还原吉大上机考试系统）

界面分为**左侧栏 + 上侧栏 + 中部区 + 右侧区**四块：

| 区域 | 内容 |
|------|------|
| 左侧栏 | 考生信息、试卷构成、**倒计时**（客观题 90 分钟 / 写作 30 分钟，分别计时；点击时钟可隐藏/显示）、进入写作 / 交卷按钮 |
| 上侧栏 | 各部分说明文字、**题号导航**（已答题打勾）、「上一题 / 下一题」按钮、Section 切换标签 |
| 中部区 | 听力为**播放器 + 进度条**；完形/阅读为**文章原文**；写作则为输入框 |
| 右侧区 | A / B / C / D **备选答案**，点击即选中 |

### 分阶段计时（与正式考试一致）
- **客观题阶段 90 分钟**：听力 + 完形 + 阅读，倒计时结束后自动进入写作。
- **写作阶段 30 分钟**：进入写作后**不能返回客观题**，倒计时结束自动交卷。
- 客观题阶段可随时点击左下角「进入写作」提前进入写作（放弃剩余客观题时间）。

### 题型与分值（与正式考试一致）
- **听力理解 25 分**：Section A 8 段短对话（16 分，每题 2 分）+ Section B 3 篇短文（9 分，每题 1 分）
- **完形填空 10 分**（每题 1 分）
- **阅读理解 45 分**（3 篇，每题 3 分）
- **写作 20 分**（自评）

> 客观题（听力 25 + 完形 10 + 阅读 45 = **80 分**）自动判分；写作 20 分请自行对照参考标准评分。正式考试 **60 分即通过**。

## 四、常见问题

- **听力听不到？** 确认 `audio` 文件夹与 `index.html` 在同一目录，且文件夹内有 `juan1_sectionA.mp3` 等 10 个文件。
- **如何查看答案与详解？** 交卷后自动生成成绩单，**每道题下方直接显示你的答案、正确答案以及完整详解**（含题型、解题思路、原文依据）；**听力题还可点「📜 查看原文」展开显示该题的听力录音原文**；**写作部分会给出参考范文**供你对照自评。并可「重做本卷」。
- **听力能重播吗？** 模拟系统允许重播方便练习；正式考试听力仅按顺序播放一次，请自行约束练习节奏。
- **写作会丢吗？** 写作可随时点「保存」，切换题目不丢失；关闭页面前也会自动尝试保存当前输入。
